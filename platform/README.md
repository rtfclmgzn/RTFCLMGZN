# RTFCLMGZN Platform v0.3

This directory contains the machine-readable platform contract.

Version 0.3 combines the Architecture Baseline, canonical 26-agent registry, Newsroom Core, private Studio, provider-neutral model execution, bounded Autopilot, and Release Manager without granting model output direct authority over workflow state, credentials, Git, publication, or distribution.

The package ships in `draft_only` mode with scheduling, owner preauthorization, automatic publication, and automatic social posting disabled. Credentials remain outside Git in the Windows DPAPI vault or environment variables. No editorial release is included.
