## What changed in v2.0

Each agent now includes:

- A stable human identity and temperament
- Private interests and recurring curiosities
- Emotional temperature and personality biases
- Sentence rhythm, diction, humor, and first-person rules
- Opening habits and signature structures
- Distinctive reporting mannerisms
- Beat-specific questions and evidence instincts
- Characteristic attitudes and natural sample lines
- Anti-homogenization instructions to prevent all editors from sounding alike
- Beat boundaries, compliance routing, and collaboration guidance
- A final self-check tailored to the editor’s role

## Integration recommendation

Load only the assigned editor’s agent file into the writing context for a given article. Keep the research brief, newsroom-wide rules, reader doctrine, and compliance instructions as separate shared context.

Do not merge all nine persona files into one generation prompt. Doing so weakens voice separation and encourages stylistic averaging.

Recommended context order:

1. Shared newsroom constitution and sourcing rules
2. Assigned editor agent file
3. Story research brief
4. Article format/template requirements
5. Final verification and compliance instructions
