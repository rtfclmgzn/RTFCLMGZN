Going live with Plus

Four steps. Two of them are just double-clicking a file.

≈ 30 minutes, most of it in Stripe
1
Set up Stripe
Only you can do this — it's your bank account
You, in a browser
  1. Sign up at dashboard.stripe.com and finish activation (bank details, business info).
  2. Product catalogue → Add product. Call it RTFCLMGZN Plus. Add three prices:
    PriceType
    $4.00 USDRecurring — monthly
    $30.00 USDRecurring — yearly
    $90.00 USDOne-time (not recurring)
    Copy each price ID — they look like price_1AbC…
  3. Developers → API keys → copy the Secret key (sk_…)
  4. Developers → Webhooks → Add endpoint
    URL: https://rtfclmgzn.com/api/billing/webhook
    Tick these 5 events: 
    checkout.session.completed
customer.subscription.created
customer.subscription.updated
customer.subscription.deleted
invoice.payment_failed
    Copy the Signing secret (whsec_…)
  5. Settings → Billing → Customer portal → turn it on, allow cancellation + card updates.
Start in Test mode (toggle, top right) if you want to try it first. Test card: 4242 4242 4242 4242, any future expiry, any CVC.
2
Paste 5 secrets into Cloudflare
Pages project → Settings → Environment variables
You, in a browser

Add each as Encrypted, for both Production and Preview:

STRIPE_SECRET_KEY        sk_…
STRIPE_WEBHOOK_SECRET    whsec_…
STRIPE_PRICE_MONTHLY     price_…   ($4)
STRIPE_PRICE_ANNUAL      price_…   ($30)
STRIPE_PRICE_LIFETIME    price_…   ($90)
Until these exist the site shows the prices with the buttons greyed out and says checkout isn't live. Nothing breaks — it just doesn't sell yet.
3
Double-click SETUP_BILLING.bat
Creates the tables and loads all 57 of your codes
One double-click

In D:\BUSINESS\RTFCLMGZN. It takes a few seconds.

Needs wrangler — if it complains 
npm install -g wrangler
wrangler login
You'll see “duplicate column name” in step 1 of that script. That's expected. Ignore it.
4
Double-click RTFCLMGZN_PUBLISH.bat
Pushes everything live
One double-click

Cloudflare rebuilds in a couple of minutes. Then the magazine, the payment system and the codes are all live.

Then unlock your own account

Go to rtfclmgzn.com → Account, sign in with your email, and enter:

Your personal code — lifetime PlusRTFC-FOUNDER

Works once, on your account only. No card, no checkout.

Want more codes later, or a % discount? 
python agents/billing/mint_vouchers.py free-months 3 --count 50
python agents/billing/mint_vouchers.py lifetime --count 5 --note "press"

It writes a .csv of codes and a .sql, and prints the one command to apply them. Nothing is live until you run that command.

% off codes are different — they only work at checkout, so make the coupon in Stripe first (Product catalogue → Coupons), then pass its ID with --coupon.

Before you market it: your Terms page still says no payments are collected, and there's no refund policy. Worth writing one line — a 14-day no-questions refund is the normal thing — before you take money from strangers.
