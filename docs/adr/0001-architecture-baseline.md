# ADR-0001 — Architecture Baseline v1.0

**Status:** Accepted  
**Scope:** RTFCLMGZN editorial operating system

RTFCLMGZN operates under the following canonical system definition:

- 26 logical agents
- 9 editorial personas
- 12 governed workflow checkpoints
- deterministic lifecycle control
- AI-operated, human-governed publication during the current phase
- no agent may publish, spend money, post externally, or change story state directly
- owner approval binds to an exact artifact hash

The documents in `docs/architecture/` are the source of truth. A later architecture decision record may supersede this baseline; informal prose elsewhere may not.
